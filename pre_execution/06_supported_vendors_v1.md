# Supported Vendors V1

الـ vendor المدعوم رسميًا في V1 هو **Huawei** ضمن مكتبة الأجهزة والقوالب التي يحددها المشروع. الدعم يعني أن model، command syntax، وvalidation profile موثقة؛ ولا يعني أن كل جهاز أو إصدار firmware مدعوم.

أي vendor أو model غير موجود في registry يصنف `unsupported` ولا يولد له أمر تنفيذي.
