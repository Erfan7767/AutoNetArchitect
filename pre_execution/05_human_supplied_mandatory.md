# Human-Supplied Mandatory

المعلومات التالية لا يجوز افتراضها: عناوين الإدارة، بيانات الاعتماد، topology الفعلية، إصدارات firmware، سياسات الأمن، نافذة التغيير، مسارات الوصول، متطلبات الامتثال، وقرار الموافقة على deployment.

كل عنصر غير متوفر يسجل بحالة `required` مع مصدر `human`، ولا يسمح النظام بتقديمه كحقيقة مكتملة.
