# Source of Truth Policy

مصدر الحقيقة الأول هو configuration والعقود versioned داخل المشروع، ثم ملفات التصميم المعتمدة، ثم مدخلات المستخدم الموثقة. لا يجوز اعتبار مخرجات AI أو التخمينات مصدر حقيقة.

كل تعارض بين مصدرين يوقف الانتقال إلى المرحلة التالية حتى يختار المستخدم مصدرًا معتمدًا أو يسجل ADR.
