# Automation and Approval Policy

يسمح دون موافقة: parsing، schema validation، static analysis، إنشاء design proposal، وتوليد dry-run report. يحتاج موافقة صريحة: حفظ configuration نهائي، الاتصال بجهاز، تغيير state، أو تنفيذ deployment.

الموافقة يجب أن ترتبط بـ actor، timestamp، target، diff، ومدة صلاحية.
